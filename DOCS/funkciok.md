# Funkciók

Az alkalmazás célja a kollégiumi adminisztráció támogatása az alábbi funkciók biztosításával:

## Diákkezelés
- Új diák rögzítése
- Diák adatainak módosítása
- Diák adatainak megtekintése

## Szülő / gondviselő kezelése
- Szülő adatainak rögzítése
- Szülő hozzárendelése diákhoz
- Kapcsolattartási adatok kezelése

## Szobakezelés
- Szobák nyilvántartása
- Szobák kapacitásának kezelése
- Szabad férőhelyek lekérdezése

## Beköltözés és kiköltözés kezelése
- Diák beköltöztetése szobába
- **Tömeges beköltözés** - több diák egyidejű beköltöztetése ugyanabba a szobába
- Diák kiköltöztetésének rögzítése
- Beköltözési előzmények nyomon követése

## Felhasználókezelés
- Felhasználók kezelése
- Admin jogosultságok biztosítása
- Jogosultság alapú hozzáférés
