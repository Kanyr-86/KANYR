# User Stories

## Teljesen új diák, szülő és lakcím rögzítése

### 1. User Story: Titkár fel akar venni egy új diákot, gondviselőt és lakcímet a rendszerben ✅

**Mint** kollégiumi titkár,
**Szeretném, hogy** fel tudjak venni egy új diákot és gondviselőt az új tanév alkalmából.
